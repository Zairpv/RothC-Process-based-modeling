# RothC-Process-based-modeling
This repository contains scripts for implementing the RothC (Rothamsted Carbon) model to simulate **soil organic carbon (SOC) dynamics** in managed forests

### Key Components

- 🔬 **Data preprocessing and input formatting** for RothC
- ⚙️ **Model parameter calibration and sensitivity analysis**
- 📊 **Simulation of SOC dynamics** over forest chronosequences
- 📁 **Scenario projections** under climate and management change
- 📈 **Visualization tools** for time series and SOC pools

All modeling steps are implemented in R using reproducible workflows with a focus on managed forest systems.
